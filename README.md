 Mental Disorder Dataset Analysis
 Project Overview

This project focuses on analyzing a Mental Disorder Dataset to understand patterns, correlations, and predictive factors related to various mental health conditions.
The main goal is to gain insights that can help identify mental health risks and improve awareness using data-driven analysis.

 Objectives

Perform Exploratory Data Analysis (EDA) to discover key trends and relationships.

Clean, preprocess, and visualize data for better understanding.

Identify factors most correlated with mental health disorders.


 Dataset Information

Dataset Name: Mental Disorder Dataset
Source: (kaggle website”)
Format: CSV 

 Features
Feature Name	Description
age	Age of the individual
gender	Gender identity
occupation	Employment type or profession
stress_level	Self-reported stress level (e.g., Low, Medium, High)
sleep_hours	Average sleep per day (in hours)
exercise_frequency	How often the individual exercises
mental_disorder	Target variable (e.g., Depression, Anxiety, None)

5. Insights & Findings



High stress and poor sleep correlate with higher mental disorder occurrence.

Regular exercise reduces the risk of anxiety and depression.

Young adults show higher levels of stress-related disorders.
